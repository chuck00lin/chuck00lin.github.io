Privacy Policy for agent-ops

Effective 2026-09-11

agent-ops is a personal, single-user automation tool operated by the owner of lalalachuck.com. It connects the owner's own Google account (Gmail, Calendar, Drive, Contacts, Docs, Sheets) to a private assistant running on the owner's own computer.

Who uses it

Only the operator. The application is not offered to the public and has no other users.

What data is accessed

Email, calendar events, files, contacts, documents and spreadsheets in the operator's own Google account, as authorised through Google's OAuth consent screen.

How data is used and stored

Data is read and written only to carry out tasks the operator requests, such as sending mail, scheduling events or organising files. OAuth tokens are stored locally on the operator's computer. No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
